# データの出典と限界

図鑑エンジンが使うデータの出どころと、どこまで信じてよいかをまとめます。

## 出典

| 内容 | 出典 | 場所 |
| --- | --- | --- |
| 基本情報・フォルム・進化条件 | PokeAPI の公開 CSV | `data/pokemon.json`、`data/evolution.json` |
| 旧作の通常草むら出現 | PokeAPI の encounters | `data/routes.json`（時間帯などの細部は出典を参照） |
| Switch 作品の入手場所 | Serebii 各ページの Locations 表 | `data/modern-routes.json`（固定出現を推測せず、条件の原文とリンクを保持。地名・条件の一部は英語） |
| 手動で確認したルート | 各ルートの `source` | `lib/dex.ts`（出典と DLC・通信・移送条件を明記） |

確認日は 2026-09-08 で、取得に失敗したページと未対応のページは `data/import-report.json` に記録しています。取り込みは `scripts/import-modern.py` と `scripts/build-evolution.py` です。

## 限界

- 全作品の全入手方法を検証したデータベースではありません。未収録のものを入手不可とは扱わない設計です。
- フォルム一覧は、HOME に保管できる全バリエーションを網羅しているとは限りません。
- 進化 CSV の条件は作品・フォルム単位で差があり、特殊な判定は出典で確認してください。
- ★評価は目安です。最短攻略は収録済みルートの優先順位比較と作品別のまとめであり、ストーリー進行・確率・実測時間を含む最適化ではありません。
- 幻の自動取得ルートは追加条件を手動で照合し、おすすめから外す `needsReview` を用意しています。
- 過去の配布は現在開催中のイベントとしておすすめしません。GO のイベントは都度公式発表を確認してください。
- 準伝説は便宜的な分類です。
