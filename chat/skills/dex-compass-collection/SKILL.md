# 収集状況の調べ方

1. 作業ディレクトリ（cwd）直下の `data/collection.md` を Read する。この skill のフォルダ（`.claude/skills/dex-compass-collection/`）からの相対パスではない。
   この会話で以前に読んでいても、答える前に読み直す。
2. 中身は「集計」「記録」「世代別の未捕獲」「分類別の未捕獲」。記録は全国図鑑 No. の並びで、`25` は 1 種、`25-30` は連番。ここに出てこない No. は記録なし（未捕獲）。
   「捕獲済み（1020匹）: No.3, 17-20 以外のすべて」のように、少ない側を書いてある場合もある。
3. 特定のポケモンを聞かれたら、その No. が各行に含まれるかで答える。名前から No. が分からないときは `reference/index.md` で引く。
4. 生データが必要なときだけ、同じ `data/` にある `state.json` を読む（`lib/state.ts` と同じ形）。
5. 表にないことは「DEX COMPASS には記録がない」と答える。推測で埋めない。
6. 入手方法・おすすめルート・Bank 対策・進化条件・サイトの説明は、この skill ではなく `dex-compass-guide` skill を使う。
