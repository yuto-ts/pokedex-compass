# サイトのデータの調べ方

パスはすべて作業ディレクトリ（cwd）直下からの相対。この skill のフォルダからの相対パスではない。

1. **特定のポケモンの入手方法・進化条件・フォルム**: `reference/species/<4桁の全国図鑑No>.md` を Read する（ピカチュウなら `reference/species/0025.md`）。
   作品ごとの入手方法（方法・条件・難易度・固定シンボル・通信・DLC・Bank経由・状態・出典 URL）、この種へ進化する条件、進化系統、フォルム一覧がある。
   No. に確信が持てないときだけ `reference/index.md` で名前から引く。
2. **次に何を集めるか（おすすめ攻略ルート）**: `data/routes.md` を Read する。ユーザーの所持ソフト・DLC・固定シンボル優先の設定で未捕獲のポケモンを作品ごとにまとめたもの。
3. **Bank 終了対策**: `data/bank.md` を Read する。終了日・移送手順と、大切な旧作個体として印を付けたもの、収録ルートが旧作だけのものの一覧。
4. **サイトの画面・用語・データの限界**: `reference/site.md` を Read する。
5. ユーザー自身の記録（捕まえた・HOME に送った・登録した）は `dex-compass-collection` skill で調べる。

答えるときは読んだファイルの内容に沿って書き、出典 URL があれば添える。表に無い作品や条件は「当サイトには収録がない」と答え、入手不可とは言わない。推測で埋めない。
